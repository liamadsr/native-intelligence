The Native Intelligence roadmap is public. You can see what we are building, vote on it, and suggest what is missing.

The full page is at [/roadmap](/roadmap).

## Where it lives

The roadmap is a set of GitHub issues in the [native-intelligence repository](https://github.com/liamadsr/native-intelligence). Every item has the [`roadmap` label](https://github.com/liamadsr/native-intelligence/issues?q=is%3Aissue%20label%3Aroadmap). The website reads those issues and refreshes every few minutes.

The same issues are also laid out as a timeline, by quarter, in the [roadmap project on GitHub](https://github.com/users/liamadsr/projects/2).

## Now, Next and Later

Each item sits in one of three columns. Its GitHub milestone is the quarter we are aiming for.

- **Now**: what we are building this quarter. Items marked **In progress** have work underway.
- **Next**: what we plan to start after that.
- **Later**: further out. These are the most likely to change.

When an item ships, we close its issue and add the `shipped` label. It then moves to the **Shipped** list.

## How to vote

Open an item's GitHub issue and react to it:

- 👍 if you want it.
- 👎 if you don't.

Each column is sorted by votes: 👍 minus 👎, highest first. Comments are welcome too. Tell us how you would use it, or how it should work. You need a GitHub account to vote or comment.

## How to suggest a feature

[Open a feature request](https://github.com/liamadsr/native-intelligence/issues/new?template=feature_request.yml) on GitHub. The form asks for the problem, what you would like, and who it is for. It gets the `idea` label.

We read every idea. Popular ones can move onto the roadmap. You can browse [all ideas](https://github.com/liamadsr/native-intelligence/issues?q=is%3Aissue%20label%3Aidea) and vote on them the same way.

For questions or a quick chat, join us on [Discord](https://discord.gg/sHtYGtkWga).
