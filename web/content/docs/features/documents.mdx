Documents are Native Intelligence's built-in wiki and knowledge base. Use them for project documentation, meeting notes, specs, runbooks, or any long-form content your team needs.

## Creating Documents

Create documents from:

- The documents view in your workspace
- Within a project (as project documentation)
- From the sidebar or quick-create menu

## Rich Text Editor

Documents use a full-featured editor with support for:

- Headings, paragraphs, and lists (ordered and unordered)
- Bold, italic, strikethrough, and code formatting
- Code blocks with syntax highlighting
- Links and images
- Block quotes
- Tables

## Organization

- **Project association** — Link documents to projects for context
- **Pin** important documents to keep them easily accessible
- **Archive** documents you no longer need without deleting them
- **Full-text search** — Documents are indexed and searchable from the global search

## Collaboration

### Comments

Add comments to documents for discussion. Native Intelligence supports **inline comments** — select specific text and attach a comment to it. Inline comments include an anchor position so readers can see exactly what's being discussed.

Comments support threading and @mentions.

### Sharing

Share documents externally using share links with view or comment access, just like captures.

## AI Integration

The AI assistant can help with documents:

- Summarize long documents
- Generate content based on workspace context
- Answer questions about document content through semantic search
