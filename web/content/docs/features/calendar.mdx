Dial8's calendar brings all your schedules into one view and connects events to captures, contacts, and actions.

## Calendar Sources

Connect calendars from multiple providers:

| Provider | Setup |
|----------|-------|
| **Google Calendar** | Connect via Google OAuth in Settings → Connectors |
| **Microsoft Outlook** | Connect via Microsoft OAuth in Settings → Connectors |
| **Local Exchange** | Access on-device Exchange calendars via the desktop app |

You can connect multiple accounts and control visibility per calendar.

## Calendar Views

Switch between different layouts to see your schedule:

- **Month view** — Traditional monthly calendar with event dots
- **Week view** — Detailed week grid with time slots
- **Day view** — Full day timeline with event blocks
- **Year view** — Annual heatmap showing event density
- **Agenda view** — Chronological list of upcoming events

## Calendar Preferences

Configure which calendars are visible from the calendar view or **Settings → Connectors**:

- **Account preferences** — Show/hide entire connected accounts
- **Calendar preferences** — Show/hide individual calendars within an account

## Events

Calendar events display:

- Title, time, and duration
- Attendees and organizer
- Location and conference links (Zoom, Meet, Teams URLs)
- Description and notes

### Event Management

- **Create events** — Add new events to your connected calendars
- **Edit events** — Update event details, time, and attendees
- **Delete events** — Remove events from your calendar
- **Drag and drop** — Reschedule events by dragging them in the week or day view

## Meeting Capture Integration

Calendar events connect directly to the capture system:

- **Linked captures** — Associate a capture (recording) with a calendar event
- **Automatic recording** — The desktop app can auto-start recording when a calendar event begins
- **Upcoming meetings** — See which upcoming events have captures associated with them
- **Participant sync** — Calendar attendees can be synced as capture participants and linked to workspace contacts

This integration means your meeting recordings are always connected to the right calendar event, making it easy to find the capture for any meeting.
