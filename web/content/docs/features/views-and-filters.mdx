Views let you create saved, filtered perspectives on your workspace data. Build a view once, and it's always up to date.

## What is a View?

A view is a saved combination of:

- **Entity type** — What you're looking at (actions, captures, contacts, projects, etc.)
- **Filters** — Conditions that narrow down the results
- **Sort order** — How results are ordered
- **Grouping** — How results are categorized
- **Layout** — List or board (kanban) display

## Creating Views

1. Navigate to any entity view (e.g., Actions)
2. Apply filters, sorting, and grouping to get the data you want
3. Save as a new view with a name
4. The view appears in your sidebar for quick access

## Layouts

### List Layout
A compact table view showing entities as rows with sortable columns. Best for scanning large amounts of data.

### Board Layout
A kanban-style view with columns representing a grouping property (typically status). Drag items between columns to update their properties. Best for visual workflow tracking.

## Filtering

Views support advanced filtering with multiple conditions:

- **Status** — Filter by workflow state or state category
- **Assignee** — Filter by who's responsible
- **Priority** — Filter by urgency level
- **Label** — Filter by applied labels
- **Project** — Filter by project association
- **Cycle** — Filter by sprint/iteration
- **Due date** — Filter by date ranges (overdue, this week, etc.)
- **Team** — Filter by team
- And more, depending on the entity type

Combine multiple filters with AND logic to create precise views.

## Sorting and Grouping

- **Sort** by any property in ascending or descending order
- **Group** results by a property (status, assignee, priority, project, label) to create visual sections

## View Scoping

Views can be scoped to different levels:

| Scope | Visible to |
|-------|-----------|
| **Personal** | Only you |
| **Team** | Members of a specific team |
| **Workspace** | Everyone in the workspace |

## Favorites

Pin views you use frequently as favorites. Favorited views appear prominently in your sidebar for one-click access.

## Duplication

Duplicate an existing view to create a variant with different filters or settings, without starting from scratch.
