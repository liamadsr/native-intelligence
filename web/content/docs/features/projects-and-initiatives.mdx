title: Projects & Initiatives
description: Organize work into projects with milestones, and connect them to higher-level strategic initiatives.
---

Projects and initiatives give your workspace a hierarchy for organizing work beyond individual actions.

## Initiatives

Initiatives are high-level strategic goals — the "why" behind your work. They represent outcomes you're driving toward over weeks or months.

### Initiative Properties

| Property | Description |
|----------|-------------|
| **Name** | The strategic goal |
| **Description** | Context and objectives |
| **Status** | Planned, Active, Completed, or Archived |
| **Owner** | The member responsible |
| **Icon & Color** | Visual customization |
| **Target date** | When the initiative should be achieved |
| **Labels** | Workspace-level tags |

### Connecting Projects

Link one or more projects to an initiative to show which concrete work supports it. This creates a top-down view: Initiative → Projects → Milestones → Actions.

## Projects

Projects are collections of related work — a feature, a campaign, a product launch. They contain actions, milestones, and documents.

### Project Properties

| Property | Description |
|----------|-------------|
| **Name** | Project title |
| **Description** | Rich-text project details |
| **Status** | Planned, Active, Paused, Completed, or Canceled |
| **Lead** | The member driving the project |
| **Initiative** | Optional link to a parent initiative |
| **Icon & Color** | Visual customization |
| **Start date** | When work begins |
| **Target date** | When the project should be completed |
| **Labels** | Workspace-level tags |

### Working with Projects

- **Assign actions** — Set a project on any action to group it under this project
- **Create milestones** — Break the project into deliverables with target dates
- **Add documents** — Attach project-specific documentation
- **Track progress** — View completion percentage based on action statuses
- **Add comments** — Discuss the project with your team

## Milestones

Milestones are key deliverables within a project — checkpoints that mark meaningful progress.

### Milestone Properties

| Property | Description |
|----------|-------------|
| **Name** | The deliverable |
| **Description** | What this milestone represents |
| **Target date** | When it should be completed |
| **Project** | The parent project |

Assign actions to milestones to track which work contributes to each deliverable. As actions are completed, milestone progress updates automatically.

## The Hierarchy

```
Initiative (strategic goal)
  └── Project (concrete work)
        ├── Milestone (deliverable)
        │     └── Actions (tasks)
        ├── Milestone
        │     └── Actions
        └── Actions (not tied to a milestone)
```

This hierarchy is flexible — you can use any level independently. Create standalone projects without initiatives, or actions without projects. Use what fits your workflow.
