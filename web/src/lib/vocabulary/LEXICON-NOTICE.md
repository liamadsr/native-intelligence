   SCOWL's full copyright file also credits the public-domain Moby Words II
   lists, 12Dicts and ENABLE, all under similarly permissive terms.

2. **US Social Security Administration baby names** (the top 1,000 names per
   year, 1880–2008), via github.com/hadley/data-baby-names. US government data,
   public domain. Only the distinct names are used, lowercased.

3. A short hand-written list of English contractions and filler words (Dial8).

`lexicon-names.ts` is generated by the same script from the same sources: the
first names (SSA baby names, public domain) that are not also a common word,
contraction, day, place, language or tech word in `lexicon-words.ts`.
